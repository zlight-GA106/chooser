# 选择器 v1.4 Go 服务端

只使用 Go 标准库。编译时把 `dist/` 中的网页、题库、图标和帮助页一起嵌入服务端程序，部署时不需要 Node.js、Python、Go 运行环境或外置网页目录。

答题、题库导入、错题统计和进度仍在浏览器本地完成。Go 只提供 HTTP(S) 页面及静态资源，不建立用户账号，不接收作答上传，不增加多端同步。

v1.4 的题库管理支持新建、查询、分页查看、编辑并校验 XML、重命名、删除与导出；与单文件桌面版同步。手机管理界面已检查 320 / 360 像素宽度，按钮自动换行，XML 编辑使用可换行的 16 像素文本和停靠保存栏。题库及管理修改仍只保存在当前浏览器，跨设备迁移请导出备份。

## 运行

Windows 双击 `选择器Go服务端v1.4-Windows.exe`，或在终端执行：

```powershell
.\选择器Go服务端v1.4-Windows.exe -addr 0.0.0.0:8088
```

同一局域网内的手机、平板或电脑访问 `http://服务器IP:8088/`。停止服务可在终端按 Ctrl+C；如果端口已被旧服务占用，请先停止旧服务或换端口。

Linux x86-64：

```sh
chmod +x ./选择器Go服务端v1.4-Linux-amd64
./选择器Go服务端v1.4-Linux-amd64 -addr 0.0.0.0:8088
```

只允许本机访问时改成 `-addr 127.0.0.1:8088`。`0.0.0.0` 是监听地址，客户端应填写服务器实际 IP。

## HTTPS 和子目录

可把 Go 服务放在已有 HTTPS 反向代理后，或直接提供证书：

```sh
./选择器Go服务端v1.4-Linux-amd64 -addr :8443 -cert server.crt -key server.key
```

证书必须被客户端信任；不要跳过浏览器证书警告。手机访问普通局域网 HTTP 时可保存题库和进度，但完整页面离线缓存通常需要 HTTPS。

如需部署到 `/chooser/`：

```sh
./选择器Go服务端v1.4-Linux-amd64 -addr :8088 -base-path /chooser/
```

访问 `http://服务器IP:8088/chooser/`。反向代理应保留该前缀。网页相对资源路径和 Service Worker 范围会跟随此目录。

## 缓存与流量

- 启动时生成静态文本资源的 gzip 表示，避免每次请求重复压缩。
- 静态资源提供 ETag；匹配 `If-None-Match` 时返回 304，无响应体。gzip 和原始文件分别使用正确的强 ETag。
- 带 `?v=版本` 的资源使用长期缓存。首页、帮助页和 `sw.js` 使用 `no-cache` 进行版本校验。
- 浏览器自身缓存题库、作答和进度，答题不会产生服务器请求；HTTPS 下离线缓存继续有效。
- `/healthz` 返回健康状态，`/api/version` 返回服务端版本；配置子目录时位于同一前缀下。

服务仅接受 GET/HEAD，禁用目录列表、源码和配置文件访问。没有上传接口或服务器题库数据库。

## 编译与验证

安装 Go 1.22 或更新版本后，在 `web/` 目录执行：

```powershell
.\build-go.ps1
```

也可使用一个未加入 PATH 的 Go SDK：

```powershell
.\build-go.ps1 -Go 'C:\路径\go\bin\go.exe'
```

脚本先执行 `go test ./...`，再生成 Windows amd64 与 Linux amd64 独立程序。无外部模块依赖，构建使用 `CGO_ENABLED=0`、`-trimpath`、`-ldflags '-s -w'`。

修改 `dist/` 后需重新编译服务端；仅替换旁边的网页文件不会更新已嵌入的内容。旧版程序可保留作回滚，重要浏览器记录请先备份。
